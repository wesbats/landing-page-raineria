# Rainéria Souza — Landing Page Oficial

Landing page profissional desenvolvida para **Rainéria Souza** (Enfermeira Obstetra, Consultora em Amamentação e Laserterapeuta), atuante em Santa Fé do Sul, Jales e região, além de consultorias online em todo o Brasil.

---

## 🌸 Sobre o Projeto

O site foi estruturado com foco em acolhimento, clareza, credibilidade clínica e conversão direta para o WhatsApp. Desenvolvido com código limpo e semântico em HTML5, CSS3 com variáveis de design e JavaScript vanilla, sem dependências externas pesadas.

### Principais Destaques:
- **Design acolhedor e responsivo:** Paleta sofisticada (terracota, blush, tons terrosos suaves e linho) e tipografia equilibrada (Playfair Display + Plus Jakarta Sans).
- **SEO Completo & Dados Estruturados:** Metadados Open Graph para pré-visualização no WhatsApp e redes sociais, Twitter Cards, Schema.org (`MedicalBusiness` e `FAQPage`), `sitemap.xml` e `robots.txt`.
- **Performance & Web Vitals:** Imagens 100% em formato WebP otimizado de alta resolução, carregamento sob demanda (`loading="lazy"`), priorização da dobra principal (`fetchpriority="high"`) e ícones em SVG sprite.
- **Identidade Visual:** Logomarca circular autêntica com caligrafia "R", acompanhada de suite completa de favicons (ICO multi-tamanho, 32x32, 192x192, 512x512 e Apple Touch Icon).
- **Recursos de Conversão:**
  - Botão flutuante de WhatsApp com efeito de pulso e mensagem contextualizada.
  - Barra inferior de ações rápidas no celular (S.O.S., WhatsApp e Instagram).
  - Triagem interativa S.O.S. Amamentação.
  - FAQ com accordion interativo acessível.

## 🚀 Como Executar Localmente

Por ser um projeto estático, não há necessidade de compilação ou instalação de pacotes:

### Opção 1: Abrir diretamente
Basta abrir o arquivo `index.html` em qualquer navegador moderno.

### Opção 2: Servidor local (recomendado)
```bash
# Com Python 3
python -m http.server 8000

# Com Node.js
npx serve .
```
Acesse `http://localhost:8000`.
